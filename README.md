# VITALOG — 건강 관리 일지 (운동·체중·보충제)

Technogym 기기 짐에서의 운동을 **가이드 세션** 흐름으로 기록하고, 체중 추세를 **심미적으로** 시각화하며, 운동 전 보충제(**Cellucor C4 / Nutricost Beta-Alanine**)를 시간대에 맞춰 추천·기록하는 오프라인 웹앱입니다.

빌드 도구·서버 없이 동작하는 **바닐라 HTML/CSS/JS(ES Modules)** 단일 페이지 앱이며, 데이터는 브라우저(`localStorage`)에만 저장됩니다. PWA로 휴대폰 홈 화면에 설치할 수 있습니다.

## 주요 기능

- **오늘의 세션(홈)** — 6단계 가이드 플로우
  1. 세션 시작 (현재 시각으로 오전 8시 전 / 저녁 19시 이후 자동 판별)
  2. 보충제 추천 + 복용 기록 + 25분 효과 대기 타이머
  3. 운동 추천 — **짐(Technogym) / 홈트레이닝 토글**, 시간대·이력 기반 분할
  4. 운동 기록 (추천 루틴 프리필)
  5. (선택) 체중 빠른 기록
  6. 세션 요약
- **일지(캘린더) 탭** — 월간 캘린더에 운동·체중·보충제 기록을 색 점으로 표시, 날짜 선택 시 그날의 기록 요약.
- **운동 탭** — 카테고리 → Technogym/홈 머신 → 운동 카드(근력 세트 `kg×회` / 유산소 `mm:ss·km`). `[WORKOUT]` 본문 인코딩/역파싱, **이력 수정/삭제**, 키워드 자동완성.
- **체중 탭** — 입력 루트 3종(일반/인바디/OKOK, OKOK 상세 19지표), 인사이트 패널(기간 탭·통계 7종·추이 드롭다운·시간축 멀티라인 차트), **데이터 품질/이상치 검출(MAD·IQR)**, 달별 네비게이터.
- **보충제 탭** — 시간대별 추천(오전 C4 / 저녁 Beta-Alanine), 복용법 안내, 일일 카페인·베타알라닌 누적, 복용 이력.
- **홈트레이닝 추천** — 보유 장비(로잉머신·벤치·10kg 덤벨 2개·전완근 기구·AB 슬라이더·스테퍼) 기반 분할 추천.
- **설정** — JSON 백업 내보내기/가져오기, 전체 초기화.

## 보충제 추천 로직

| 세션 | 추천 | 핵심 |
|------|------|------|
| 오전(8시 전) | **Cellucor C4** | 카페인 ~150mg, 1스쿱/찬물 180ml, 운동 20–30분 전. 처음엔 ½스쿱, 하루 2스쿱 한도 |
| 저녁(19시 이후) | **Nutricost Beta-Alanine** | 무자극(수면 방해 없음), ~2–3.2g, 따끔거림은 정상, 효과는 누적적 |

> ※ 보충제·운동 안내는 일반 정보이며 의학적 조언이 아닙니다.

## 실행

ES Modules는 `file://`에서 동작하지 않으므로 정적 서버가 필요합니다.

```bash
python3 -m http.server 8099
# 브라우저에서 http://localhost:8099 접속
```

GitHub Pages(저장소 Settings → Pages → 브랜치 루트)로 그대로 배포할 수 있습니다.

## 구조

```
index.html            앱 셸 + 탭 + 가이드 세션 컨테이너
css/styles.css        다크 네온 디자인 토큰/컴포넌트
js/app.js             라우터 / 탭 네비 / 토스트 / SW 등록
js/model.js           카테고리·루트 상수, MemoEntry 모델
js/store.js           localStorage CRUD + JSON 백업
js/util.js            DOM·날짜·포맷 헬퍼
js/workout.js         머신 사전, [WORKOUT] 인코딩/디코딩, 에디터
js/weight.js          루트 판별·인코딩, 지표 사전, 인사이트 패널
js/chart.js           SVG 시간축 멀티라인 추세 차트
js/supplement.js      제품 데이터, 시간대 추천, 복용 기록
js/recommend.js       이력 기반 운동 추천 엔진
js/session.js         6단계 가이드 세션(홈)
js/settings.js        백업/초기화/면책
manifest.webmanifest  PWA 매니페스트
sw.js                 오프라인 캐시 서비스워커
```

데이터 모델·인코딩 규칙은 안드로이드 `Memo_Collection` 앱의 체중탭·운동탭 명세를 따릅니다(단일 `MemoEntry.text` 인코딩, 입력 루트 색상, 머신 카테고리 사전).
